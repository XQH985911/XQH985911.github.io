## Local Preview

```bash
# Clone the repository
git clone https://github.com/XQH985911/XQH985911.github.io.git

# Open with VS Code
code XQH985911.github.io

# Install the Live Server extension, then right-click index.html → Open with Live Server
```

Alternatively, simply open `index.html` in a browser — the theme toggle works without a server.

## Deployment
